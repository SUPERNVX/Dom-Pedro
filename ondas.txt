    <h2 class="sec" data-reveal style="--d:80ms">Quatro camadas de código<br>por trás do papel recortado.</h2>
    <p class="lead" data-reveal style="--d:140ms">Sim — dá para fazer tudo via código, sem imagem. O efeito é um SVG com várias ondas empilhadas, cada uma num grupo que desliza em sua própria velocidade. O relevo de “papel” vem de uma sombra projetada; a textura, de um padrão de fibras; e o movimento, de um loop sem costura.</p>

    <div class="steps">
      <div class="step" data-reveal>
        <div class="num">01</div>
        <div>
          <h3>Camadas &amp; parallax</h3>
          <p>Seis ondas empilhadas de trás para frente. Cada grupo translada em velocidade própria — as da frente mais rápidas — criando profundidade com um único <code>translate3d</code> por camada.</p>
          <span class="tag">transform · GPU</span>
        </div>
      </div>
      <div class="step" data-reveal>
        <div class="num">02</div>
        <div>
          <h3>Sombra paper-cut</h3>
          <p>Um <code>feDropShadow</code> deslocado para cima faz cada crista projetar sombra sobre a camada de trás. Como o filtro fica “cozido” na textura da camada, transladar não recalcula o blur — roda liso.</p>
          <span class="tag">filtro SVG</span>
        </div>
      </div>
      <div class="step" data-reveal>
        <div class="num">03</div>
        <div>
          <h3>Trama de fibra</h3>
          <p>Sobre cada onda, o mesmo caminho é repintado com um <code>&lt;pattern&gt;</code> de linhas finas e baixa opacidade. É isso que dá o grão de papel artesanal que você vê na referência.</p>
          <span class="tag">pattern</span>
        </div>
      </div>
      <div class="step" data-reveal>
        <div class="num">04</div>
        <div>
          <h3>Loop sem emenda</h3>
          <p>A curva é periódica no comprimento de onda. Quando o grupo desliza exatamente uma onda, o quadro final é idêntico ao inicial — o reinício é invisível, para sempre.</p>
          <span class="tag">seno + harmônicos</span>
        </div>
      </div>
    </div>

<script type="text/plain" id="codeRaw">// 1. a curva de cada camada (periódica => loop perfeito)
function waveY(x, base, amp, wl, phase) {
  const k = (Math.PI * 2) / wl;
  const h = Math.sin(k * x + phase)
          + 0.35 * Math.sin(2 * k * x + phase * 1.3)
          + 0.18 * Math.sin(3 * k * x + phase * 0.7);
  return base + (amp * h) / 1.53;
}

// 2. o loop: cada camada desliza 1 comprimento de onda
function tick(dt, t) {
  for (const L of layers) {
    L.x -= L.speed * dt;                 // parallax (frente mais rápida)
    if (L.x < -L.wl) L.x += L.wl;        // emenda invisível
    const bob = Math.sin(t * L.bf + L.ph) * L.ba;
    L.el.style.transform =
      `translate3d(${L.x}px, ${bob}px, 0)`; // sombra cozida na camada
  }
}</script>
